# Python_Practice_projects
Here i have listed some python basic projects that i made while practicing , i update this repo whenever i practice python.

1.Rent_calculator - This is a simple Python-based Rent Calculator that helps friends or roommates calculate how much each person needs to pay for shared monthly expenses in a flat or hostel.When multiple friends live together, they usually share expenses like rent, food, electricity, WiFi, and groceries. Manually calculating everyone's share can be confusing. This program solves that problem by automatically dividing the total expenses among all friends.
